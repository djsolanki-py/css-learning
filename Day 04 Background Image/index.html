Learning CSS Background Image

I am learning CSS background-image. This property is used to set an image as the background of an element.


I am also practicing background-repeat, background-position, background-attachment and background-size.


I am using background-attachment: fixed to understand how the background image behaves while scrolling.


The background-repeat property can be used with values such as repeat, no-repeat, repeat-x and repeat-y.


The background-position property controls where the background image is placed.


The background-size property can be used with values such as cover and contain.
